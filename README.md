# Break It Down

Break It Down is an AI-powered productivity app that helps users overcome procrastination by breaking large, overwhelming tasks into five small, clear, and actionable steps.

Instead of staring at a huge task and not knowing where to begin, users simply describe what they need to accomplish, and the AI generates a simple step-by-step plan that is easy to follow.

## Live Demo

**Live App:** https://break-it-down.ai.studio

## The Problem

Many people struggle to start important tasks because they feel too big or complicated. This often leads to procrastination, stress, and unfinished work.

Break It Down solves this problem by turning one large goal into five manageable steps, helping users focus on one step at a time.

## AI Feature

The core feature of Break It Down uses Generative AI to analyze the user's task and produce exactly five logical, actionable steps.

### System Prompt

```
You are an expert productivity assistant.

Your job is to break any task into exactly five clear and practical steps.

Rules:
- Always return exactly five steps.
- Keep each step short and actionable.
- Arrange them in logical order.
- Make the steps realistic and easy to follow.
- Do not add introductions or conclusions.
- Return only the numbered list.
```

## How to Run Locally

1. Clone the repository

```bash
git clone [https://github.com/YOUR_USERNAME/Break-it-down.git](https://github.com/hashir-1433/Break-it-down)
```

2. Open the project folder

```bash
cd Break-it-down
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

5. Open the local URL shown in the terminal.
